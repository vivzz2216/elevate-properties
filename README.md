# ELEVATE PROPERTIES — Architecture & Selected Residences

> An architectural studio designing site-responsive private residences across the Mediterranean and coastal California.

---

## 🏛️ Project Overview
**Elevate Properties** is an architectural portfolio and studio website built with modern, semantic HTML5, custom CSS styling, and responsive design.

### Key Features
- **Monumental Typography**: Barlow Condensed for bold architectural headers paired with Inter for clean editorial UI text.
- **Curated Selected Works**: Showcase of private residences including *The Horizon House*, *Villa Solstice*, and *Cala Serena*.
- **Material Archive**: Tactile exploration of materials like raw cast concrete, aged travertine, dark oak, and blackened bronze.
- **Practice Disciplines**: Highlights site-responsive architecture, climate-first engineering, and custom interior design.
- **Interactive Project & Inquiry Overlays**: Modals for exploring project details and commissioning dialogues.

---

## 🚀 Getting Started

Simply open `index.html` in any modern web browser, or launch a local server:

```bash
# Python 3
python -m http.server 8000

# or Node.js
npx serve .
```

Visit `http://localhost:8000` to explore the site.
